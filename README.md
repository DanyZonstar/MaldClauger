# MaldClauger: игры

Две браузерные игры. Открываются в любом браузере, на компьютере и на телефоне.

Играть онлайн: https://danyzonstar.github.io/MaldClauger/

- **Зацеп** (`zacep.html`): зацепись за Сапсан и продержись на крыше.
- **Диггер** (`digger.html`): пробеги бомбоубежище, собери противогазы и уйди от полиции (она приезжает с шансом 80%).

Это игры, а не инструкция. Зацепинг и походы в заброшенные бункеры опасны для жизни и запрещены законом.

## Как включить ссылку для всех (GitHub Pages)

Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
ветка `claude/vigilant-hamilton-5qmsb2`, папка `/ (root)` → Save.
Через минуту-две игры откроются по ссылке выше.
